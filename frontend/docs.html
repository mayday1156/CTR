使用文档

快速上手 CTR Insight，从环境搭建到完成一次完整的分析预测。

目录 1. 快速开始 2. 数据准备 3. 导入真实数据并训练（一键） 4. 数据导入与预测 5. 动态数据分析 6. 模型说明

1. 快速开始

本项目使用虚拟环境隔离依赖。首次使用请先初始化环境：

# Git Bash / MSYS2 终端
bash setup.sh

# 启动后端
bash start.sh

启动后访问 http://127.0.0.1:8000/ui/ 打开网站。

2. 数据准备

项目默认展示模拟数据（与真实 Ali-CCP 数据同结构），用于先把网站跑通。 生成模拟数据：

./venv/Scripts/python.exe scripts/generate_mock_data.py \
  --n-users 20000 --n-samples 200000 --seed 42

3. 导入真实数据并训练（一键脚本）

当你拿到真实 Ali-CCP 数据后，只需两步即可让网站切换到真实数据 + 真实模型：

  1. 放置数据：把 4 个 parquet 文件放进 data/real/ 目录：
    • common_features_train.parquet
    • common_features_test.parquet
    • sample_skeleton_train.parquet
    • sample_skeleton_test.parquet
  2. 运行一键脚本（保持后端已启动 bash start.sh）： 
    # Git Bash / MSYS2 终端
bash train_real.sh

# 或 Windows CMD（双击 train_real.bat）
# 可加参数：bash train_real.sh --epochs 5

脚本会自动完成：检测数据 → 训练 CTR + CVR 模型 → 切换数据源到 real → 热重载后端同步到网页。 完成后刷新浏览器，网站即显示真实数据与真实模型（工作台侧边栏与概览页会有「真实数据」徽章）。

如需自定义训练参数：

./venv/Scripts/python.exe backend/train_real.py --epochs 5 --min-count 10

想切回模拟数据：运行 ./venv/Scripts/python.exe backend/train_models.py --data-dir data/mock --source mock 然后调用 POST /api/reload（或直接重启后端）。

4. 数据导入与预测

  1. 进入「工作台 → 数据导入」
  2. 上传数据文件（parquet / csv / xlsx）
  3. 网站自动解析并引导字段映射
  4. 点击「开始预测」，得到 pCTR / pCVR / pCTCVR
  5. 导出结果 CSV

5. 动态数据分析

在工作台的「数据分析」页，可以：

  • 查看曝光 → 点击 → 转化的转化漏斗
  • 选择两个类目维度做交叉 CTR 热力图
  • 查看单字段 CTR 分布、行为序列长度分布
  • 诊断字段覆盖率与 unknown 率

6. 模型说明

CTR 与 CVR 预估基于 DeepFM 模型（FM 一阶 + FM 二阶 + DNN）， 采用 field-aware embedding 建模 20 个结构化特征字段。

训练模型（默认数据源）：

./venv/Scripts/python.exe backend/train_models.py --min-count 3 --epochs 2

模型产物（词表、CTR/CVR 权重、评估指标）输出到 model/artifacts/。
