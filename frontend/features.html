产品功能

CTR Insight 提供四大核心能力，覆盖从数据到洞察的完整闭环。

数据导入与字段映射

支持多种格式，智能解析阿里私有特征编码，网站引导完成字段映射与质量校验。

  • 支持 parquet / csv / xlsx / json 格式上传
  • 自动解析 feature_list 三层分隔编码（20 个结构化字段）
  • 字段映射引导 + 数据质量校验报告
  • 模拟数据与真实数据无缝替换
📥

动态数据分析

交互式探索海量曝光日志，从多个维度洞察点击率规律。

  • 转化漏斗：曝光 → 点击 → 转化逐层流失
  • 维度交叉 CTR 热力图（类目、广告位、投放策略等）
  • 单字段 CTR 分布、行为序列长度分布
  • 字段覆盖率与 unknown 率诊断
📊

CTR / CVR 智能预估

基于 DeepFM 深度学习模型，批量预估每条曝光的点击率与转化率。

  • DeepFM 模型：field-aware embedding + FM 二阶 + DNN
  • CTR + CVR 双任务预测（pCTR / pCVR / pCTCVR）
  • 批量预测 + 结果分布可视化
  • 结果一键导出 CSV
🧠

模型评估与对比

完整的评估体系，量化模型排序能力与概率校准质量。

  • AUC / LogLoss / GAUC 多指标评估
  • 概率校准曲线与校准系数
  • GAUC 拆解用户内排序能力
  • LR / GBDT / DeepFM 多模型对比
